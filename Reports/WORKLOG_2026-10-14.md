# RK Classes — Aaj ka kaam (14-Oct-2026)

Format: **Task Name** — short description.

## A. WhatsApp: Normal / Business choose karna
- **Web (`rkWaOpen`)** — saare WhatsApp buttons (attendance absent, fees, receipt, student, finance) ab pehle poochte hain: Android me Normal ya Business, PC par WhatsApp Web ya Desktop app. Last choice upar aata hai.
- **Mobile app** — WhatsApp dabane par "Send from which WhatsApp?" sheet; chat chune hue app me hi khulti hai. Ek hi app installed ho to seedha khulta hai.

## B. User delete / restore
- **Soft delete** — Admin Users page se user delete kar sakta hai (row rehti hai, login band). Super Admin aur khud ko delete nahi kar sakta.
- **Restore** — Deleted Records me naya "Deleted Users" section / app me "Users" tab; Restore par user dobara Active.
- **SQL/60** — `Users.IsDeleted / DeletedAt / DeletedBy`.

## C. User Rights — proper
- **Rights turant lagte hain** — pehle rights login ke waqt session/token me jam jaate the. Ab har request par DB se live padhe jaate hain (web + app), admin ke save karte hi lagu. User deactivate / delete / switch-off hote hi turant logout.
- **Web pages par rights enforce** — pehle sirf sidebar link chhupta tha, URL type karke koi bhi logged-in user Fees/Student/Faculty/Masters/Marks/Expenses/FeeSetup khol sakta tha. Ab har page par wahi right chahiye jo mobile API me chahiye (admin sab dekh sakta hai).
- **Privilege escalation band** — normal user apni profile form me `RoleId=1` bhej kar khud admin ban sakta tha; ab role/status/email/phone/password sirf DB se (web + app API). `ToggleActive` aur `ChangePassword` bhi sirf admin / apna account.
- **"Add/Edit …" modules** — web menu aur mobile API alag flag dekhte the (View vs Edit). Ab View ya Edit koi bhi tick ho to right mil jaata hai.
- **Edit => View** — Edit tick hone par View server par bhi apne aap judta hai; unknown module / Super Admin rights change refuse.
- **Zero-right user ka redirect loop** theek kiya; login ke baad pehla allowed page khulta hai; open-redirect (`returnUrl`) band.
- **SQL/61** — `teacher_attendance` / `teacher_payment` modules (kisi script me the hi nahi, isliye Permissions screen me dikhte nahi the) + Users list ka "N modules" count (revoke kiye hue ginte the).

## D. Class Representative (CR / Monitor)
- **Kaun** — class ka koi ek student; admin Users → "Class Representatives" (web) ya Modules → "Class Reps" (app) se banata hai: student chuno, username/password do, "sirf apna batch" option.
- **Kya kar sakta hai** — apni class ki student attendance (aaj + pichhle 2 din) aur teacher attendance (teacher, subject, topic, time) — web aur app dono me.
- **Kya nahi** — fees, marks, dusri class, students list, dashboard, tasks, users — sab server par band (allowlist). Parents ke phone sirf apni class ke.
- **Scope live** — class/section/batch student se live padhe jaate hain; student inactive ho ya class badle to CR ka access apne aap badalta/band hota hai.
- **CR rights** — sirf 3 modules (student attendance, teacher attendance, test marks — section J dekho); Permissions screen me aur kuch de nahi sakte. Admin switch off / password reset kar sakta hai.
- **Teacher attendance entries** — CR sirf apni entries dekhta / delete karta hai; admin ko "Added by" dikhta hai.
- **Mobile app** — CR login par alag Home (class card + 2 buttons), sirf Home + Profile tabs. App start / resume par `GET /api/auth/me` se rights refresh.
- **Bug fix (sabke liye)** — teacher attendance me Hindi subject/topic `????` ban jaata tha; ab parameterised SQL, Hindi sahi save hota hai. Out-time in-time se pehle ya bahut lamba topic ab saaf message ke saath refuse.

## G. Delete / inactive => summary se bahar, Deleted me dikhe, admin restore kare
- **Summary se bahar** — inactive/deleted student ab dashboard cards (students, new today, present/absent, fees this month), Fee Payments list, Fees Due, Marks/Test reports, Attendance date-grid, Finance class drill-down se nikal jaata hai. Deleted expense dashboard ke "Expenses this month" me nahi ginta. Inactive teacher teacher-payments, teacher-attendance aur lectures ki list/summary se nikal jaata hai. (SQL/62 live par chal gaya; C# queries code me.)
- **Deleted Records me ab** — Students, Faculty, Users, Receipts + naya "Other Deleted Records": Expense, Teacher payment, Teacher attendance entry, Lecture (web + app "Other" tab). Admin kisi ko bhi Restore kar sakta hai.
- **Note** — Users me "Inactive" (sirf band kiya) user Users list me hi rehta hai (waha se Activate hota hai); "Delete" karne par wo Deleted me jaata hai.

## H. Sir / Ma'am greeting
- **Teacher aur Admin** ko ab har jagha "FirstName Sir" / "FirstName Ma'am" dikhta hai (web dashboard greeting, sidebar user tile, top-bar; app Home greeting + Profile). Gender pehle linked Faculty profile se, nahi to User ke Gender se (Users → Edit → Gender; app ke user form me bhi). Gender pata na ho to poora naam waise hi rehta hai. "Dr. Ravi Kumar" / "KAPIL YADAV SIR" jaise naam se bhi sahi "Ravi Sir" / "Kapil Sir" banta hai. Accountant / Class Rep ka naam wahi rehta hai.
- **SQL/63** — `Users.Gender` (live par chal gaya).

## I. CR test marks + dashboard batch-wise count
- **CR test marks** — Class Representative ab apni class ke saare students ke test marks daal sakta hai (web + app). Sirf apni class ke students, pichhle 7 din ke test, marks 0 se max ke beech, test name zaroori. Marks Report / Top Students / Print wagairah band. App ke CR Home par "Test Marks" tile. **SQL/64** — jo CR pehle se bane hain unko ye module mil jaata hai.
- **Students by Class me batch-wise** — har medium ke neeche ab batch split: "English 77" ke neeche "Morning 40 · Evening 37". Batches master se dynamic (naya batch banao to apne aap aayega); jis medium me kisi ka batch nahi wahan line nahi dikhti; batch-less students "No batch" me. Web dashboard aur app Home dono me. (Ye split server ke naye code se aata hai — web deploy ke baad hi live app me dikhega.)

## J. Har CR ke rights alag se chunna (web + app)
- **Class Representatives page** — CR banate waqt aur Edit me 3 checkboxes: **Student attendance / Teacher attendance / Test marks**. List me "Rights" column. Kam se kam ek right zaroori. Rights badalte hi turant lagu (CR ko dobara login nahi). App ke "Make CR" sheet aur edit dialog me bhi wahi checkboxes. Edit me rights na bhejo (sirf password/on-off) to rights waise hi rehte hain.
- **Users → Permissions** page par bhi CR ke ye 3 modules dikhte hain (aur kuch nahi de sakte).

- Pehle se bane test (jisme marks save hain) ko kholne par uska "Out of" apne aap wahi aa jaata hai aur lock rehta hai (pencil icon se zarurat par badal sakte ho). Web me ye field pehle se tha; mobile me ab same. Sirf app change hai — naya APK build karna hoga.
