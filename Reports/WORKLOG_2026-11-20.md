# 20 Nov 2026 - Study Follow-up module (web + app)

**What it is:** like Fee Follow-up, but for studies. Two kinds of entry in one table (`StudyFollowups`):
- **Parent call** - how (call / WhatsApp / visit...), spoke to, about (studies, test marks, homework...), how it ended, *what the parent said*, *what we told*, next follow-up date.
- **Oral test** - subject, topic, result (Gave it / Partly / Could not give / Not taken), optional score, remark.

**Parent notification:** an oral test result goes to the parent automatically (tick box, on by default) as a notification of kind `study`
("Sharma Kabir could NOT give the Maths oral test ... Score 3/10 ..."). A call summary goes only if "Also send what we told to the parent" is ticked.
Deleting a follow-up takes the notification back.

**Web** (`/StudyFollowup`, sidebar "Study Follow-up"): search a student to add; summary with date presets (Today / Yesterday / 7 / 30 days / This month / All) + from-to dates,
type, oral result, subject, class / medium / batch, done-by, "follow-up due"; two views - Date & time wise, Student wise; Excel (CSV) export.
Student page: all-time totals, phones (call / WhatsApp), add form (call / oral tabs), full history with its own type + date filter.

**App:** Modules -> Academics -> Study Follow-up (same right as web). Same summary (two tabs, date chips, filters, export), student page, add sheet.
Parent app: notifications show the new `study` kind (violet icon, "Study" filter chip appears when there is one). Web parent portal too.

**Right:** new module key `study_followup` (Users > Permissions, group Academics). Admin always has it. The site creates the table and the module row by itself on start (also `SQL/82_StudyFollowups.sql`).
