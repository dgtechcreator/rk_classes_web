## A. Company Work Log

1. **Notifications (Parents + Teachers, App + Web)** — Student ki har activity par parent ko notification: Absent / Late / Present, Marks entry (ya test miss), Fee receipt, Lecture (naya / update / cancel / complete). Teacher ko lecture assign / update / cancel par notification. App me Home par 🔔 badge + notifications screen (aaj / kal ke hisaab se, child aur type filter); web me parent portal me 🔔 + Notifications page; staff web bell me ab notifications bhi dikhte hain (pehle sirf tasks). Same event dobara save ho to duplicate nahi banta; 3 din se purani attendance par notification nahi jata. (SQL/71)
2. **Student login** — Pehle sirf father/mother ke number se account banta tha. Ab student ka apna phone number bhi chalta hai; student ko wahi dikhta hai jo parent ko (attendance, marks, fees, notifications, report). App me tab ka naam "Parent / Student".
3. **Search — father / mother ke naam se** — Students list (web + app), Fees search aur Finance list me ab student ya father ya mother ka koi bhi word likhne par result aata hai (jaise "PAL VIVEK RAJESH REKHA" me pal / vivek / rajesh / rekha). Admission no., roll no. aur phone se bhi.
4. **Class Notes + Daily Practice Papers (naya module)** — Class (aur medium / batch) ke hisaab se PDF, Word, PPT, Excel, image upload. Web (`/Notes`) aur app (Modules → Notes & Papers) dono se. Upload par us class ke parents / students ko notification. Parent / student app me "Notes & papers", web me "Notes & Papers". Files public link par nahi, login ke baad sirf apni class ki. User rights me naya module "Notes & Practice Papers". (SQL/72)
5. **Student Report — pie chart** — Attendance (Present / Absent / Late pie), subject-wise marks bar, fees pie (Paid / Discount / Balance). Parent ko Home par "Full report"; staff (admin, principal, HM, VP) ko Student Profile me — "Student 360 View" right se admin decide karega kisko dikhe. Web par Student 360 page aur parent portal me bhi charts.
6. **App ka poora naya theme (Blue)** — Red se Admin Home jaisa blue: header, tabs, buttons, cards sab. Ek hi theme file se colour badal sakta hai.
7. **Login page naya** — Blue hero me school ka asli logo + "RK Classes" lettering (red / blue), upar card me Staff / Parent-Student toggle.
8. **Cards aur alignment har page par** — Admin Home aur compact (stat cards 56dp, quick tiles 46dp, class rows patli). Users list naye card me (search, role / modules pills, ⋮ menu). Students, Faculty, Fees search me naya common card (avatar, naam, class / medium / batch pills). Stat tiles (Fees, Attendance, Teacher screens) aur Modules tiles chhote.

## B. Technical notes
- **DB:** SQL/71 (`StudentActivities`, `ParentAccounts.NotifSeenAt`) aur SQL/72 (`ClassNotes` + module `class_notes`) — dono website start hone par khud bhi ban jaati hain, isliye chalana optional. SQL/70 pehle ki tarah.
- **Backend:** `ActivityNotifier` (attendance / marks / fees / lecture services me jura, error aaye to save kabhi fail nahi hota); `StudentRepo.GetAll` me search ab C# me token match; `ParentRepo.GetChildren` ab inline SQL (`Students.Phone` bhi match); `NotesApiController`, `NoteFileStore` (files `App_Data/class-notes` me); `GET /api/students/{id}/report`; `/api/parent/notifications`, `/api/parent/notes`; `POST /api/tasks/notifications/read-all`.
- **App:** naya `file_picker` package; Student Report, Notes, Parent notifications screens; `PersonCard`, compact `StatCard`.
- **Test:** local scratch DB par API se end-to-end (attendance, marks, lecture series / cancel, notes upload / download, parent aur student login, search); app web preview me dekha. Web build 0 errors, `flutter analyze` me koi error nahi. **Asli phone par test baaki** (khaas kar Notes upload ka file picker).
